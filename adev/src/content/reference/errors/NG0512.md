# Texto ausente na hidratação

Este erro é parecido com o [erro NG0500](errors/NG0500), mas significa que o processo de hidratação do Angular esperava um nó de texto em um ponto específico do DOM e não encontrou nada ali. Consulte a página do [erro NG0500](errors/NG0500) para ver as causas relacionadas à manipulação direta do DOM.

## Uma causa comum: o HTML do servidor mudou antes da hidratação {#a-common-cause-the-server-html-changed-before-hydration}

A hidratação reaproveita os nós de texto que a renderização no servidor (SSR) produziu. Se algo remover ou mesclar esses nós de texto antes de o browser executar a aplicação, o nó que o Angular procura desaparece.

Fontes comuns são um minificador de HTML, um proxy ou CDN que reescreve a resposta, uma extensão do browser ou código da aplicação que escreve texto com `innerHTML` fora do Angular.

## Depurando o erro {#debugging-the-error}

Consulte o [erro NG0500](errors/NG0500) para dicas de depuração de causas relacionadas à manipulação direta do DOM.

Compare o HTML que o servidor enviou com o HTML que o browser recebeu. Use o código-fonte da página em vez do inspetor de elementos, porque o inspetor mostra o DOM depois que a hidratação já foi executada. Se o texto estiver presente na resposta do servidor, mas ausente no browser, procure uma ferramenta intermediária que reescreva o HTML.

Se você não controla o HTML de um component, pode adicionar o atributo `ngSkipHydration` ao nó host dele como último recurso. Isso desabilita a hidratação para o component e para os filhos, e deve ser considerado um bug que precisa ser corrigido.
