# Nó de hidratação ausente no caminho

Os builds de produção mostram este erro quando o Angular não consegue encontrar um nó durante a hidratação. O Angular segue um caminho que salvou durante a renderização no servidor (SSR), mas um nó nesse caminho está faltando. Isso significa que o DOM no browser é diferente do HTML do servidor.

Builds de produção não incluem mensagens de erro, então você vê apenas o código `NG0509`. Builds de desenvolvimento mostram o mesmo problema do [erro NG0502](errors/NG0502), e a mensagem informa o nó host e o caminho.

## Causas comuns {#common-causes}

As causas são as mesmas do [erro NG0500](errors/NG0500). Também verifique mudanças vindas de fora da sua aplicação, por exemplo de um recurso de CDN ou de uma extensão do browser. Leia [CDNs e extensões do browser](guide/hydration#cdns-and-browser-extensions) no guia de hidratação.

## Depurando o erro {#debugging-the-error}

- Se você conseguir ver o problema em um build de desenvolvimento, use esse build. A mensagem `NG0502` informa o nó host e o caminho.
- Compare o HTML de produção com o HTML do seu servidor local. Se você vir elementos `__cf_email__`, ou se nós de comentário estiverem faltando, provavelmente a causa é um recurso de CDN.
- Abra a página em um perfil do browser sem extensões. Se o erro desaparecer, uma extensão está alterando a página.
