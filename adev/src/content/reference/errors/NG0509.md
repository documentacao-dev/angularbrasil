# Nó ausente no caminho de hidratação

Builds de produção mostram este erro quando o Angular não encontra um nó durante a hidratação. O Angular segue um caminho que salvou durante a renderização no servidor (SSR), mas um nó desse caminho está ausente. Isso significa que o DOM no browser é diferente do HTML que veio do servidor.

Builds de produção não incluem mensagens de erro, então você vê apenas o código `NG0509`. Builds de desenvolvimento mostram o mesmo problema como [erro NG0502](errors/NG0502), e a mensagem informa o nó host e o caminho.

## Causas comuns {#common-causes}

As causas são as mesmas do [erro NG0500](errors/NG0500). Também verifique mudanças vindas de fora da sua aplicação, como um recurso de CDN ou uma extensão do browser. Leia [CDNs e extensões do browser](guide/hydration#cdns-and-browser-extensions) no guia de hidratação.

## Depurando o erro {#debugging-the-error}

- Se você conseguir ver o problema em um build de desenvolvimento, use esse build. A mensagem `NG0502` informa o nó host e o caminho.
- Compare o HTML de produção com o HTML do seu servidor local. Se você vir elementos `__cf_email__` ou se nós de comentário estiverem ausentes, provavelmente é um recurso de CDN.
- Abra a página em um perfil do browser sem extensões. Se o erro desaparecer, uma extensão está alterando a página.
