# Coleção usada no @for não é iterável

Um loop `@for` repete sobre um array ou sobre um valor que implementa o [protocolo de iteração](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Iteration_protocols), como um `Map`, um `Set` ou um generator. Este erro significa que a coleção não era nenhum dos dois, o que mais comumente acontece com um objeto simples:

```angular-ts
@Component({
  template: `@for (item of items; track item) {
    {{ item }}
  }`,
})
class Test {
  items = {first: 'a', second: 'b'};
}
```

`null` e `undefined` não geram erro e não renderizam nada, então este erro só aponta um valor que está presente, mas não pode ser iterado.

## Corrigindo o erro {#fixing-the-error}

Para repetir sobre as entradas de um objeto simples, use o [pipe KeyValue](/api/common/KeyValuePipe):

```angular-ts
@Component({
  imports: [KeyValuePipe],
  template: `@for (item of items | keyvalue; track item.key) {
    {{ item.key }}: {{ item.value }}
  }`,
})
class Test {
  items = {first: 'a', second: 'b'};
}
```

Se a coleção vier de uma chamada de API ou de outra fonte dinâmica, confira se o valor é a própria lista. Uma resposta que envolve a lista em outro objeto, como `{data: [...]}`, é uma causa comum deste erro.
